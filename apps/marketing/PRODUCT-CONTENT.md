# Spontra 官网产品素材

官网首页的立意是“Spontra，24 小时只为你的投资团队”，围绕两个核心：主动发现问题、按你的投资逻辑 / 知识水平 / 投资目标定制报告。首屏使用真实产品截图。

## 首屏截图

| 位置 | 文件 | 说明 |
| --- | --- | --- |
| 桌面 | `public/product/app-research.webp`（1920 × 1286） | 应用首页：净值卡片、研究汇报列表与一份汇报详情 |
| 手机（≤720px） | `public/product/app-report.webp`（900 × 1063） | 同一份汇报详情的单栏裁切 |

两张图在 `product-assets.json` 的 `hero.desktop` / `hero.mobile` 中登记，构建时检查文件是否存在，宽高用于防止布局跳动。

## 隐私要求

截图来自线上应用。替换截图前必须隐去真实账户信息：净值卡片中的净值、累计盈亏、持仓净市值、现金与杠杆率使用示意数字（当前为 $128,460.52 等，各项数值保持自洽），页面图注同步说明“账户数字为示意”。不放入账号、账户编号或其他不想公开的私人信息。

## 替换流程

1. 以 1440 × 900、2 倍像素比截取应用首页，把净值卡片数字替换为示意数据。
2. 裁去页面两侧留白与右下角浮动按钮，导出为宽 1920 的 WebP；手机图裁取汇报详情栏，宽 900。
3. 覆盖 `public/product/` 下的同名文件，必要时更新 `product-assets.json` 中的宽高。
4. 运行 `npm run marketing:build`，按本目录 README 与根目录 AGENTS.md，经 origin/main 自动发布。
