# Spontra 产品内容接入清单

网页已经为三类真实产品内容留好位置。当前产品演示位标注“内容准备中”；体验示例明确标注为示意，不接入用户账户数据。

## 1. 产品演示

提供一段 45–90 秒的横向录屏，依次展示：进入 Spontra、发现已经准备好的问题、查看证据、切换阅读方式。也可以先提供主界面截图，后续再加入视频。建议 MP4 / H.264，16:10 或 16:9，至少 1440 像素宽。另提供一张视频封面。

当前位置：首屏下方的产品窗口。

## 2. 三种研究视图

提供同一份研究的三张截图：先看结论、对照证据、风险条件。三张图的事实、判断与数据口径应一致；保留可读的文字和实际交互结构。建议 PNG / WebP，至少 1440 像素宽。

当前位置：“同一个问题，多一种看清的方式”章节的三个切换视图。

## 3. 完整研究案例

提供一个完整案例：原始投资假设、新证据及日期、公开来源、变化的含义、具体复核条件。可以提供案例页面截图和文字；收益数字与客户评价只有在有真实证据时才加入。

当前位置：“一次投资，完整的判断过程”章节。

## 提供前检查

隐藏账号、账户编号、私人持仓和其他不想公开的信息。请注明哪些内容可以公开，以及图片中的英文是否需要一起重写。

## 接入说明

资源存放在 `apps/marketing/public/product/`。在 `product-assets.json` 中填写相对路径，例如 `product/walkthrough.mp4` 和 `product/summary.webp`。保持未准备好的项为 `null`。

- `walkthrough.src`：产品演示 MP4；`walkthrough.poster`：封面。
- `researchViews.summary / evidence / risk`：三个实际界面截图。
- `caseStudy.src`：真实研究案例截图。加入时也同步替换网页案例文字与来源。

运行 `npm run marketing:build` 生成中英文页面。文案在同一脚本的 `copy` 对象内维护。随后按本目录 README 和根目录 AGENTS.md，经 origin/main 自动发布官网 Worker。

页面当前保留全部四条研究路径和自优化大脑；旧图谱、旧滚动场景和旧动画代码已移除。新动画由 `public/marketing.css` 与 `public/marketing.js` 管理，支持暂停与系统减少动态效果设置。
