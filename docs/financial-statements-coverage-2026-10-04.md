# Financial Statements 全章提取验证（2026-10-04）

## 问题与修复

原有 admin 的季度核心指标是产品摘要，只有有限字段；原始 Inline XBRL 事实清单虽然包含更多标签，仍不是 Financial Statements 原始报表。新增独立的完整报表入口，按归档的 SEC 10-Q / 10-K 选择文件，列出章节内所有原始 HTML 表格，保留每行、单元格、比较期间、合并单元格及整章正文。季度摘要明确标记不是完整报表。

提取以 SEC 目录中的 Financial Statements 目标定位章节，截止下一 SEC Item。ORCL 年报 Item 8 将读者指向 Item 15 的独立报表章节；现在跟随该明确引用，避免错误地将短引用段落视为完整报表。章节内的分部表格、附注、没有 XBRL 标签的单元格、空白和破折号均保留；有标签的单元格关联精确值、期间、单位、scale、维度和原文字符位置。年累计保持原期间，不自动当单季。

## 能力边界

这是可审计的原始报表与正文提取，不代表所有文字都已解释为标准财务指标。源文件缺失、无法可靠定位章节、无表格、非法合并跨度、图像内容等显式报告缺口。图像不做 OCR；不支持的 XBRL 转换保留原文及状态。通用跨公司会计分类、无标签附注的语义结构化、所有公司格式的章节识别仍有边界。不会将未披露补零。
