## 实现范围

- 首页宏观 / 行业研究区域读取真实公共 API；没有在产品代码内写入合成报告。
- `/research?type=macro|industry` 提供列表与行业搜索。
- `/research/:reportId?version=:version` 固定报告版本，支持历史链接、刷新、前进 / 后退。
- 报告正文使用 harness 从结构化研究生成的 Markdown；沿用现有安全 Markdown 渲染器。来源、版本、数据时点、覆盖范围与原文语言可见。
- 明确区分无已发布内容、未覆盖搜索、请求失败、无权限、撤回、有限覆盖与待复核状态。重试只发 GET。

## 可复现命令

启动站点开发服务后运行：

```bash
ACCEPTANCE_BASE=http://127.0.0.1:4188 node scripts/public-research-browser-acceptance.mjs
```

可用 `CHROMIUM_PATH` 指定 Chromium；`ACCEPTANCE_OUTPUT` 指定日志 / 截图目录，默认 `/tmp/spontra-g4-ui`。该旅程在浏览器中拦截公共 API，以明确标为 synthetic 的报告验证 UI。它不会调用研究生成、发布、数据库写入或模型。
