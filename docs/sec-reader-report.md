# 面向投资判断的通用财报报告

本次优化适用于新生成的定期财报及合并业绩材料。研究问题按公司业务和重要性选择，没有公司 ticker 分支、固定客户名单、资本开支金额或折旧年限。8-K/6-K 独立事件继续使用简析路径；历史已保存报告兼容读取，不因前端升级宣称完成重分析。

## 解决的根因

旧 synthesis 同时要求“600–1200字”“最多1800字”“不要复写专题”，页面将该摘要标为完整正文。presentation 强制所有完成节点出场，导致文章依赖内部任务粒度；主编覆盖率又和数值验证并列，容易被误读为可信度。

新契约将研究底稿和读者文章分开。`readerReport` 是唯一完整正文，`summary.report` 由文章程序化生成，供分享、保存和后续历史研究使用。旧报告只显示“报告概览”“专题解读”，不通过改标题假装重新写过。

## 生成与发布链路

1. 原文、附件、XBRL 与披露发现：保留原来的来源、字符位置和附件覆盖。
2. context：加载可用历史，同时取得冻结的行情快照。行情失败作为缺口，不阻断有依据的业务研究。
3. manager：按“变化→业务机制→利润/现金/资产负债→估值要求→反证”提出问题。重要订单需研究客户集中、付款能力、最低采购/取消条款及转化速度；治理细节按财务影响排序。
4. node + manager-review：保留指标原文定义、期间、币种；检查会计因果、调整口径、资产寿命、常态与风险的区别及一次性因素替代。缺债务时优先检索资产负债表，而非用单笔发行代替总额。
5. deterministic financial lens：只用期间、币种、定义可对齐的数据算现金流桥和折旧量级。金额不是模型自由生成。
6. synthesis：输出3–8节有递进关系的文章、1–5项变化和1–4条可验证条件。必须有独立反面论点及估值边界，高重要性研究必须整合；低重要性底稿无需成为章节。
7. structural validation：证据和节点引用、重要主题覆盖、变化基线、完整段落、独立空头章节、证伪时点与重复段落检查。
8. editorial-review：在独立 Workflow step 审阅实际对外标题、结论、正文、变化、计算框及行情，而不是仅审阅分析任务是否“完成”。重大问题触发一次独立 editorial-revision step，再独立复审；仍失败则不发布、不覆盖旧报告。每个模型调用单独持久化和重试，避免审稿＋重写＋复审共享十分钟 step。

独立审稿表示独立调用和职责，不表示已用另一个模型或人工证明结论正确。它沿用 reasoning model 配置和既有失败回退策略。

## 关键边界

| 问题 | 系统行为 |
| --- | --- |
| 营业利润率被归因于所得税或非运营收益 | 研究和最终审稿明确检查损益表层级，发现重大错误需重写，不能只降低显示分数 |
| 普通FCF与管理层口径方向相反 | OCF−总capex与OCF−管理层净capex在头部并列，显示差额、期间和定义；后者标为测算，检查客户资金是否已计入OCF及其履约义务 |
| 高capex与未来费用 | 仅原文存在可对齐寿命时展示量级压力测试；列出资产范围、同速持续、零残值和全部费用化等假设，不作为明年新增折旧预测 |
| 缺少债务/现金/毛利口径 | 顶部解释对杠杆、流动性、分部比较的限制；区分数据未取得与公司未披露，允许从本期原文补齐 |
| 某行业没有工业企业指标 | 不制造FCF或折旧场景；提示毛利口径可能不适用，由研究按行业选替代指标 |
| “本期新增”的误判 | 变化表列以前/本期/含义，缺历史原始基线时降级为“基线待补”；旧模型文本不充当历史事实 |
| 旧判断被重复结果“验证” | 要求检验因果机制与原预测；一次性收益消失但被新一次性因素替代，不能宣称盈利正常化 |
| 有数字就算通过 | 展示指标的值、单位、定义和引用由对应事实回填；同环比由可比序列填充。覆盖率分母包含整个标准指标集合，不忽略缺失序列 |
| 再次审稿无法通过 | 任务失败并保留上次可用报告；不得回退成一个看似完整、实际只有摘要的新报告 |

## 行情与估值

`sec/market.ts` 沿用项目的 Yahoo 数据来源，以日线已完成交易日的收盘价建立快照。过滤当前未完成交易日、未来时间、错 ticker 和无效数值。报告生成后不会随页面访问重新取价。

事件窗口用发布前最后一个可用交易日到发布后最多三个完整交易日，明示起止日期及实际交易日数，不以自然日伪装三日行情，也不把价格波动归因于财报。

P/E 仅在同币种、连续四季或当前完整年度的正摊薄EPS可用时计算，标注盈利截止期；外国发行人可能存在ADS换算差异时不计算。缺少最新实际流通股数和完整债务时不输出市值或EV/EBITDA。没有价格时必须明确无法评价当前价格的吸引力。当前版本不接入一致预期、分析师目标价或外部客户信用调查，材料不足时留下可执行的数据缺口。

## 阅读与追溯

顶部先呈现关键判断边界。阅读顺序为核心结论与现金/折旧框、季度变化、关键数据、完整递进正文、证伪条件。不同内容使用并列数字、前后对比、连续段落、结论短句和观察清单；正文限制行宽，移动端改为单列。

正文每节提供“这意味着”和可展开原文。机器ID、字符位置、内部处理状态、研究覆盖分数和版本只在核查层显示；覆盖分数明确不是可信度。存储仍保留底稿与来源，不删除审计证据。

## 验证与尚未证明的部分

- 合成资本密集企业：两种FCF、折旧量级与利润规模比较。
- 合成零售企业和银行：缺寿命/缺capex时不强套场景，允许资产负债表补债务。
- 错误注入：累计数混用、币种不一致、多个冲突寿命、错误引用、缺空头/证伪条件、段落重复、伪造历史基线、模型虚构指标值、审稿拒绝保留旧报告。
- 行情：未完成/未来日线过滤、实际交易日窗口、失败降级与缺EPS。
- 页面：完整正文、顶部数据缺口、正负FCF并列、原文和诊断默认折叠、桌面及移动宽度。

上述是程序及合成样本验证，不是对所有公司实际模型输出的正确性保证。上线前后应选择不同业务、不同数据覆盖的真实财报运行并人工抽查。此次未重算线上ORCL报告，未批量重生成历史文章。
