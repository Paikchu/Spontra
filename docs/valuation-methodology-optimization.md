# Spontra 估值体系优化：驱动因子、反向估值与校准闭环

更新日期：2026-10-27。状态：方法优化方案，叠加在[构建方案与资料链路](valuation-assessment-design.md)和[独立开发交接规格 v1](valuation-assessment-implementation.md)之上；与两者冲突处以本文为准，本文未提及的部分沿用原规格。本文不针对任何一家公司，所有样本均为合成数字。

**本文解决三个问题：现有计算核让增长不需要再投资、三情景之间没有一致性和概率约束、"市场计了多少价"没有工具可算。解决思路是把所有能由数据确定的量交给代码，把 Agent 的工作收窄到证据、叙事和有理由的假设，并用公司自身历史、库内横截面和事后实际值约束它。**

**一、现有方法的诊断**

| 现状 | 问题 | 后果 |
| --- | --- | --- |
| 共同现金流核 `CF[t]=CF[t-1]*(1+growth[t])` | 增长率与再投资脱钩，乐观情景可以在不增加资本开支的前提下高增长 | 乐观值系统性偏高，范围上沿失真 |
| 终值 `TV=CF[5]*(1+g)/(r-g)` | 终值增长不要求再投资，也不检查终期 ROIC 是否高于资本成本 | 五年模型终值占比常超七成，而终值本身最不可信 |
| 折现率按情景各自设定 | 经营风险已经体现在情景现金流里，再在 r 上区分等于重复计风险 | 情景差异来源不可解释，敏感性无法分离 |
| 三情景为三组独立输入 | 没有要求情景之间共享一个叙事和一组驱动因子，也没有概率 | 范围只有端点，没有中心，安全边际只对基准计算 |
| 预期差靠外部共识 | 没有独立共识时错杀催化不能进 8 分档，`supported` 几乎不可达 | 研究做完仍然 pending，读者得不到"市场计价了什么"的回答 |
| 假设只要求"有理由" | 没有把假设放到公司自身历史和库内同口径分布中定位 | Agent 可以给出超出公司历史最大值的利润率而不触发任何检查 |
| 研究预算平均分配 | 不知道哪个假设最影响价值，就无法把阅读预算投向最重要的证据 | 读了很多原文，关键假设依旧薄弱 |
| 没有事后校准 | 每版假设不与之后的实际值比较 | 体系无法随时间改进，也无法量化自己的偏差 |

计算核原有的优点保留：折现率归属、股权桥接、终值占比披露、显式零与缺失分离、三情景顺序校验、负值保留。

**二、计算核升级：驱动因子与再投资一致性**

把 `fcff` 的现金流来源从"上期现金流乘增长"改为驱动因子路径；`fcfe`、`revenue_fcfe` 与 `affo_dcf` 继续使用共同核，但同样套用第四节的情景一致性与终值约束。

每年的驱动因子：`revenueGrowth[t]`、`operatingMargin[t]`（EBIT 口径，含 SBC）、`taxRate[t]`、`salesToCapital[t]`（增量收入与增量投入资本之比）。

```text
Revenue[t]      = Revenue[t-1] * (1 + revenueGrowth[t])
EBIT[t]         = Revenue[t] * operatingMargin[t]
NOPAT[t]        = EBIT[t] * (1 - taxRate[t])
Reinvestment[t] = (Revenue[t] - Revenue[t-1]) / salesToCapital[t]
FCFF[t]         = NOPAT[t] - Reinvestment[t] + normalization[t]
```

再投资包含资本开支减折旧摊销加营运资本增加；收入下降时再投资可以为负，但负再投资的绝对值不得超过当年折旧摊销，超出部分按 0 处理并记入 issues。`salesToCapital` 的起点由公司最近三年实际值计算（代码），Agent 只能带证据偏离。

终值采用价值驱动公式，而不是对第五年现金流直接乘 `(1+g)`：

```text
reinvestmentRate_T = g / ROIC_T
TV = NOPAT[5] * (1 + g) * (1 - reinvestmentRate_T) / (r - g)
```

约束：`0 <= g < r`；`g` 不高于估值币种的无风险利率（作为名义经济增长的代理，来源须登记）；`ROIC_T >= r`，否则终期增长不创造价值并要求 Agent 说明为何仍假设增长；`ROIC_T` 高于公司近五年 ROIC 中位数时必须给证据。终值占比超过 80% 记 `tv_share_high` 缺口，报告必须把终值假设列为首要失效条件。

可选的十年双阶段：第 6 至 10 年增长率、利润率和 ROIC 线性收敛到终期值，再在第 10 年末套终值公式。适用于高增长公司；选用与否是模型选择的一部分，由代码按"近三年收入增长中位数高于终值增长上限三倍"自动建议，Agent 可以带理由改动。首版仍不做年中折现，报告继续声明。

合成样本：`NOPAT[5]=100`、`g=0.03`、`ROIC_T=0.15`、`r=0.10` 时，再投资率 0.20，`NOPAT[6]=103`，终期自由现金流 82.4，`TV=1177.14`。原公式把 100 当作可全额分配的现金流会得到 1471.43，高出约四分之一。若 `ROIC_T=0.10` 等于资本成本，`TV=1030`，增长几乎不增加价值。再投资样本：收入从 1000 增至 1100，`salesToCapital=2`，再投资 50；利润率 15% 的 NOPAT 为 165，`FCFF=115`。

**三、折现率由代码给基线，三情景共用**

折现率不再是每个情景各自的研究假设。代码先算出带来源的基线，Agent 只能做带证据的调整，并且同一报告三情景共用同一个 `r`；`r` 的不确定性放进敏感性表，而不是情景。

```text
costOfEquity = riskFree + beta * equityRiskPremium (+ sizeOrCountryAdjustment)
costOfDebt   = max(interestExpense_TTM / averageDebt, riskFree) 或已披露的加权利率
WACC         = E/(D+E) * costOfEquity + D/(D+E) * costOfDebt * (1 - taxRate)
```

| 输入 | 来源与规则 |
| --- | --- |
| riskFree | 估值币种的十年期国债收益率，须作为带日期的事实登记；没有登记来源时不计算基线，折现率整体成为显式假设并标注 |
| beta | 优先用已冻结的日线历史对宽基指数回归（至少两年周度收益），输出回归区间；历史不足或 R² 过低时退回行业层级 beta，并把来源登记为证据 |
| equityRiskPremium | 研究假设，须引用公开发布的估计并登记日期 |
| E、D | 市值用冻结参考价乘经济股数；债务含租赁负债，取最近期末存量 |
| costOfDebt | 利息费用除以平均有息负债，低于无风险利率时取无风险利率 |
| taxRate | 近三年有效税率中位数，亏损年份剔除；无正税基时用法定税率并标注 |

样本：`riskFree=4%`、`beta=1.2`、`ERP=5%` 得权益成本 10%；税前债务成本 6%、税率 25%、`E/V=0.8`、`D/V=0.2` 得 WACC 8.9%。

**四、情景规范：一个叙事、一组驱动、显式概率**

每个情景是一个一致的叙事，不是三组各自拨动的参数。Agent 为每个情景提交：

- `narrative`：一句话说明在什么世界里这组数字成立；
- 驱动因子路径：全部四个因子逐年给出，不允许只改一个因子；
- `triggers`：进入该情景可观察到的信号，和对应的 `invalidation`；
- `evidenceIds`：支撑这一路径的证据；
- `probability`：研究假设，三者之和为 1；没有依据时允许不给概率，此时不输出概率加权值，只输出端点。

一致性由代码检查：乐观情景的增长高于基准时，其再投资不得低于基准；利润率上升时需要说明来源（规模、提价、结构），并至少有一条证据；三情景的终期 ROIC 不得相差超过资本成本的一倍。违反时退回修正，不排序结果冒充情景。

情景数值要放到两个分布中定位，由代码计算分位：

1. **公司自身历史**：从已验证 XBRL 事实计算近八到十年每个驱动因子的年度值，给出最小、最大、中位和四分位。假设落在历史范围之外时记 `assumption_out_of_history_range`，Agent 必须用证据说明为什么这一次不同；悲观情景低于历史最小值同样需要证据，例如已经披露的结构性冲击。
2. **库内横截面**：在 Spontra 已覆盖公司中，按同一口径计算同一因子的分布（所有公司，不区分行业，附行业子集时标注样本数）。这是通用的参考类，不是"同行倍数"。利润率或 ROIC 高于横截面 90 分位的终期假设必须说明护城河证据，并与生意质量维度交叉引用。

样本：某因子八年历史为 10、11、12、12、13、14、15、16，基准假设 14 落在 75 分位；乐观假设 18 高于历史最大值，触发缺口；悲观假设 9 低于最小值，同样触发。

**五、反向估值：把"市场计了什么价"算出来**

新增 `reverse_dcf` 分析（不是估值模型，不产生情景价值），在有效参考报价存在时总是运行：

- 固定 `r`、终值公式、税率、再投资规则与基准情景一致；
- 求解使股权价值等于当前市值的单一参数路径，首版支持两种：恒定收入增长率（利润率取基准路径），或恒定终期利润率（增长取基准路径）；
- 用二分法在单调区间求解，输出隐含值、与基准假设的差距、以及差距对应的历史分位。

恒定增长的闭式样本：`FCF[1]=100`、`r=0.10`、股数 100、价格 20、净债 0，市值 2000，隐含永续增长 `g = r - FCF[1]/V = 5%`。五年模型用数值解，样本以单调性检查和收敛容差 1e-6 验收。

隐含路径直接服务错杀催化维度：预期差不再只能来自外部共识，而是"市场隐含路径与基准路径的可量化差距，加上说明市场为何错的证据"。相应修改结论规则：错杀催化进入 8 分档的条件改为**二者其一**：已核验的独立共识与基准的差距，或反向估值隐含路径与基准的差距且差距超过该因子历史四分位距。`supported` 的其他条件不变。隐含路径与基准一致时，这是"市场已经计价"的直接证据，错杀催化上限为 6 分。

**六、估值范围的定义与展示**

范围不再是"三个数"。计算器为每份报告输出：

| 输出 | 定义 |
| --- | --- |
| `range` | `[bear, bull]` 每股价值区间 |
| `base` | 基准每股价值 |
| `expected` | 概率加权每股价值；无概率时为 null |
| `implied` | 反向估值隐含点所对应的驱动因子值，以及把它放回基准路径的价值差 |
| `marginOfSafety` | `1 - price/base`，沿用原规格 |
| `downsideCoverage` | `bear/price - 1`，负值表示悲观情景下的跌幅 |
| `expectedUpside` | `expected/price - 1` |
| `sensitivities` | 每个驱动因子单独 ±1 个标准步长（增长与利润率 1 个百分点、`r` 与 `g` 0.5 个百分点、`salesToCapital` 10%）对基准价值的影响，按绝对值排序 |
| `terminalShare` | 终值现值占比 |

样本：悲观 50、基准 100、乐观 160，概率 0.25、0.5、0.25，参考价 80：`expected=102.5`，安全边际 20%，`expectedUpside=28.1%`，`downsideCoverage=-37.5%`。敏感性样本用恒定增长模型 `V=FCF/(r-g)`，`FCF=100`、`r=0.10`、`g=0.03` 得 1428.57：`g` 上调 1 个百分点为 1666.67（+16.7%），`r` 上调 1 个百分点为 1250（−12.5%），`FCF` 上调 10% 为 1571.43（+10%）。排序为 `g`、`r`、`FCF`，页面用水平条形图展示。

估值安全维度的锚点改为由这些数字驱动：安全边际非正时不进 6 分档（原规则保留）；`downsideCoverage` 低于 −40% 且悲观情景概率不低于 0.25 时不进 8 分档；`terminalShare` 超过 80% 时不进 8 分档。这些是下限规则，不是自动打分。

**七、确定性诊断块：Agent 必答的事实**

在研究开始前由代码从已验证事实计算下列指标，放进材料包，并要求每个维度的 rationale 对相关指标逐条回应。无法计算的项记为缺口，不补零。

| 维度 | 指标 | 计算 |
| --- | --- | --- |
| 增长兑现 | 每股收入增长、有机增长 | 收入增长减去已披露并购贡献；每股口径用稀释加权股数 |
| 增长兑现 | ROIC 趋势 | `NOPAT / (有息负债 + 股东权益 − 超额现金)` 近五年 |
| 生意质量 | 毛利率与经营利润率的跨周期波动 | 近八年标准差与最大回撤 |
| 财务韧性 | 净债务/EBITDA、利息覆盖倍数 | 含租赁负债；覆盖倍数用 EBIT 除利息费用 |
| 财务韧性 | 到期墙 | 从债务附注读出的未来五年到期额，Agent 用 `read_filing_section` 登记证据后由代码汇总 |
| 财务韧性 | 现金跑道 | 现金及短期投资除以近四季平均自由现金流流出，仅当自由现金流为负 |
| 盈利质量 | 应计比率 | `(净利润 − CFO) / 平均总资产` |
| 盈利质量 | 自由现金流转化率 | `(CFO − CapEx) / 净利润`，净利润非正时不计算 |
| 盈利质量 | SBC 占收入比、股数年化变化 | 后者用期末普通股近三年复合增速 |
| 盈利质量 | CapEx / D&A | 低于 1 持续三年以上提示投入不足 |

稀释股数采用库存股法：Agent 从股权激励附注登记未行权期权数量、加权行权价和未归属 RSU 数量，代码按参考价计算净增股数。样本：基础股数 100、期权 10 份、行权价 10、参考价 25，行权所得 100 回购 4 股，经济股数 106。无法读到附注时稀释储备仍为显式假设，并记缺口。

**八、Agent 分工与研究循环**

分工原则：模型只做三件事，提取并登记证据、给定性维度评分并说明理由、为驱动因子假设给出叙事和依据。所有数字由代码计算；模型提交的任何数值都只能是"假设"或"从登记证据抄录的披露值"，计算器拒绝没有 sourceRef 或 rationale 的数字。

研究循环改为"先算后读"：

1. **先验基准**：代码用公司历史中位数生成一组先验驱动因子和先验情景（历史 25、50、75 分位），跑一遍计算器，得到先验价值、终值占比、敏感性排序和反向估值隐含点。不需要模型参与。
2. **定向研究**：研究阶段的提示词只列出敏感性最高的两个驱动因子和隐含路径与先验的差距；Agent 的阅读预算优先投向这两个因子的证据，其余因子沿用先验并标注"未经研究的历史先验"。这使每次原文阅读都针对一个能改变价值的问题。
3. **假设提交**：Agent 按第四节提交三情景，代码做一致性与分位检查，不通过则退回，最多两次。
4. **红队**：一个独立的短循环（最多 4 轮、3 次正文读），输入只有基准情景和它的证据列表，任务是找出最可能错的两个假设及反证，不允许修改假设。结果进入 `counterEvidenceIds` 与失效条件。
5. **成稿**：compose 只接收结构化状态：诊断块、驱动因子与分位、计算结果、证据登记表、红队结论；不接收研究阶段的对话历史。

Agent 不做的事：不估算折现率、不心算终值、不给出"合理倍数"而不说明来源、不在没有读到正文的情况下引用搜索摘要。

关于模型的定性能力有一项可用证据：仅凭标准化匿名财务报表，大模型对下一期盈利方向的判断可以达到与分析师相当的水平（Kim、Muhn、Nikolaev，2024）。这支持把模型用于"报表读出来的方向判断"，但该研究只检验方向，不检验数值和置信度，所以本文坚持数值归代码。可选扩展：增加一个只喂标准化报表的独立方向判断，作为增长兑现维度的参考信号，在第九节的校准闭环中累计命中率后再决定是否计入评分。

**九、校准闭环：假设与实际的差距**

每个报告版本保存三情景的逐年驱动因子。新财年或新 TTM 的已验证事实发布后，代码计算每个因子的实际值与基准假设的差、落在哪个情景之间、以及是否超出 `[bear, bull]` 区间，写入 `valuation_calibration`（version_id、factor、horizonYear、assumed、actual、error、scenarioHit）。

用途：

- 下一次评估的材料包带上本公司历史预测误差，Agent 必须在相关因子的理由中回应；
- Admin 展示跨公司的因子误差分布与区间覆盖率（实际值落入 `[bear, bull]` 的比例）。覆盖率远高于概率之和说明范围过宽，远低于说明过窄；
- 不做"结论与之后股价"的回测作为评分依据，价格变动混入了与估值无关的因素；只校准因子。

**十二、实施顺序**

1. 计算核：驱动因子路径、价值驱动终值、敏感性、概率加权、反向估值；纯函数，用第十一节样本验收后可独立合并。
2. 数据层：历史分布、横截面分布、诊断块、折现率基线；全部从已验证事实计算，不调用模型。
3. 先验基准与定向研究提示；情景合同与一致性检查。
4. 红队循环与成稿的结构化交接。
5. 校准表与 Admin 展示。

每一步的验收仍以本仓库的类型检查、样本测试和真实公司实跑为准；真实公司的结果只用来检查流程与证据，不用来调整评分锚点。
