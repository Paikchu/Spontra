# Spontra Admin 工作区

## 导航与状态

Admin 是 Spontra 唯一的 Web 管理端。侧边栏上方的公司选择器读取管理端发行人目录，页面地址的 `ticker` 是整个工作区的公司范围；公司内容与工具不自行选择或回退到另一家公司。旧 Admin 地址仍可打开相应的新入口。

- iOS 公司 Dock 对照（SpontraApp `cfbf598`，`CompanySubView`）：估值、动态、业务地图、财务报表。构建使用该版本保留的 iOS AppIcon 资产。
- 公司工具：公司、L1 原始文件、L2 原始文件、报告评测。L2 来源引用包含披露编号和来源锚点，跳回同一家公司的 L1。
- 全局管理：数据与生成控制、模型配置、消息与运维。公司名单保留不展开的跨公司简表。通过「查看公司」进入单公司页；单公司页直接显示操作与详情，不再重复展示一行表格。

## 发布边界

App 对照区通过 iOS 使用的 `/api/business/v1/*` 读取发布态。同一份已发布研报 HTML 通过现有 `/artifact-frame` 沙箱渲染；SwiftUI 原生图表由 Web 使用同一份数据对照呈现，不直接运行 SwiftUI。任务、输入、译文、运行和发布操作继续使用现有管理 API，不旁路权限，不由浏览触发。估值历史图根据报告日期阶梯变化，不把最新区间套在过去所有收盘价上；有多期记录时核对更新前后的区间，以及情景模型的终值占比和来源。此改动不增 Worker、D1 表、路由网关或任务类型；现有架构图的部署与边界关系不变。

## 上线验收

- 在估值输入 CRWV，再切换到 GOOGL。当前页不变，报价、估值与来源无串读；返回和刷新恢复 URL 中的公司。
- 依次检查动态、业务地图、财务报表、公司、L1、L2、报告评测。动态打开实际发布的财报，桌面及窄屏都能读正文；L1/L2 可切披露编号，并由 L2 引用跳到 L1。
- 全局菜单不受公司切换影响。保留已有运行、采集、复核和模型配置入口，但不使用生产写操作冒充验收。
- 在真实浏览器检查品牌图标、18px 页面标题、对齐、换行、可滚动区域、键盘搜索和移动抽屉。
